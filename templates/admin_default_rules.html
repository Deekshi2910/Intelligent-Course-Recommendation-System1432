Assumption Management Guarantees
  • 1. Zero Code Execution: All default rules are declarative structures evaluated through deterministic Python comparators (zero eval() / exec()).
  • 2. CGPA Non-Hallucination: Missing CGPA (DR04) is strictly never assumed or defaulted to arbitrary numbers. Academic eligibility verification is required.
  • 3. Prerequisite Non-Assumption: Unknown prerequisites (DR05) are marked as unverified and cannot be assumed satisfied without course completion evidence.
  • 4. Non-Monotonic Retraction: When a student later enters actual interests or career goals, any temporary default assumptions are automatically retracted. Actual preferences always supersede defaults.
